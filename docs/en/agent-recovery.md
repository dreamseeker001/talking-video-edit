# Agent orchestration and recovery

Success means a playable film that meets the task, not a script running without an agent. Full-film semantic decisions, grading choices, caption phrase boundaries and visual review are normal agent responsibilities. Recovery means fixing a tool failure or working around a demonstrated tool limitation.

Run-VideoTask is an optional phased helper: Prepare performs preparation/ASR/Prep; Cut validates the final source plan, derives a native EDL and retimes with OpenEdit; Finish consumes an agent-prepared base, frozen contract, transcript and final execution plan, then runs Prep, annotation initialization, preflight, Render and Check. Use -Phase Prepare|Cut|Finish. Agent-action-required is an internal handoff: continue in the same task without asking the user to approve ordinary stages. Agent-recovery-required identifies a failure and logs; inspect them and resume the nearest valid stage.

Between Cut and Finish, inherit the source frozen snapshot, selection and style files. Grade/compose uncaptioned footage using existing tools. Preserve the source plan; bind an execution plan to the actual retimed words. Semantic sections and caption cues differ: regroup transcript.chunks at complete phrase boundaries, mark the reviewed segmentation final, update provenance, then Prep and derive annotations. Changing a boundary field alone does not regroup captions. Do not guess frame snapping: automatic projection requires matching retained word sequences; partial cuts or mismatches go to the agent.

Recover within the existing scope using local native commands or a small task-specific helper. Preserve originals and valid outputs; reuse good ASR and Cut results. Before regenerating annotations, back up presentation and policy-review as a pair. Avoid repeated new runs solely to escape stale files. Retry only with new diagnostic evidence; if no authorized alternative remains, report the specific blocker. Never clear keywords/cards, relax checks, fabricate a pass, or retranscribe edited footage to hide lost words. Grade decisions need actual evidence; preserve-color decisions are legitimate if justified. Technical/visual checks do not prove listening quality.

Ask the user only for necessary unresolved content choices, new name spellings, preference conflicts, required external assets or authority beyond the current request. Preserve uncertain speech when possible. Do not add paid services, upload media or change global preferences as a technical workaround.

Maintain an Agent recovery table in the main task.md: stage, trigger/log, action, authorization boundary, impact, validation, status and improvement suggestion. At delivery, give the film first, then summarize recoveries, verification limits and improvements. With no recoveries say so. Separate reusable deterministic fixes from decisions that should remain with the agent and candidates requiring more tests. Do not convert a one-film workaround into a global preference or a new orchestration platform.
