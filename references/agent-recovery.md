# Agent 编排与兜底

目标是符合本片要求的可播放成片。脚本正常交接给 Agent 不算失败，也不需要用户批准下一步。Agent 的全片语义判断、校色判断、字幕短语边界、参考取舍和视觉检查属于正常职责；只有弥补工具限制或修复异常才称为兜底。

## 阶段交接

Run-VideoTask 是可选的分阶段辅助入口，不是独立自动剪辑器：
- Prepare：准备、复用有效ASR、Prep，返回 agent-action-required。Agent 通读全片并完成计划，同一任务内继续 Cut，不询问“继续吗”。
- Cut：校验 final 计划、派生原生EDL、执行Cut和原生重定时、核对保留段的逐词内容后投影。部分词删除、分块变化等不适合自动投影时由 Agent 检查原生结果。
- Agent：沿用源任务冻结的 preferences.snapshot.md、style-selection.json 和 style 目录，不重新采用更新后的全局偏好。用FFmpeg完成未烧录字幕底片的校色/合成/规格化。语义段与字幕cue不是一回事；按完整短语拆字幕，不能把“一直”拆开，也不能按固定字数冒充语义判断。保留源计划；剪后执行计划记录来源。先实际重组 transcript.chunks，再标记final、计算来源哈希，再Prep，最后生成注释。只修改boundaries字段不会改变字幕。
- Finish：对已绑定合同、底片、最终转录和计划的run运行Prep、注释初始化、预检、Render、Check。返回technical-check-passed后，Agent查看实际输出并交付，不把返回状态称为完整质量通过。

调用参数：`Run-VideoTask.ps1 -Phase Prepare|Cut|Finish -Media <对应媒体> -RunKey <原生run键>`。Finish用底片和其原生run；-Render:$false仅预检。不要把Prepare的状态当成用户输入请求。工具异常返回agent-recovery-required及日志位置，Agent在授权范围内继续排查。

## 允许的兜底与恢复

脚本错误、字幕重绑定、工具支持范围内的渲染适配、规格转换、OpenEdit/FFmpeg之间的本地替代均可由Agent自行处理，前提是保留用户意图、原片、已有效结果和验证强度。用任务内小脚本或原生命令处理，不建设自有剪辑器或新平台。

先读错误及对应输入，找到具体原因；从最近有效阶段恢复。有效Cut不再重做，源ASR不因字幕修改而重跑。旧注释需要重建时先备份presentation和policy-review两份，再整体派生，避免孤立半成品；不要仅为了换文件名不断新建run。每次重试应有新的诊断依据；同因无新证据不盲重试，尝试已授权的本地替代，仍不能完成时如实报告具体阻塞。

不允许以清空关键词、移除卡片、放宽检查、伪造pass或重新转录剪后片掩盖丢字来兜底。校色未执行或尚未判断不能标记pass；合理选择保持原色时写判断证据。帧率转换记录实际值和原因。画面检查不代替听辨，语境纠字不等于音频复核。

需要用户的是新人物字形、影响内容的真实歧义、未解决偏好冲突、必须提供的外部素材或超出现有授权的行动。语义不确定且可保留时先保留。不主动开付费服务、不上传素材、不修改全局偏好来解决本片技术问题。候选长期偏好仍遵守偏好确认流程。

## 兜底记录与交付

在本片task.md追加“Agent兜底”表；跨多个run时在主task.md集中索引，不新建追踪平台。每条记录：阶段、触发原因/日志、采取动作、为什么未越界、影响或偏差、验证证据、状态、可复用的完善建议。正常语义决策不逐条记为故障。兜底尚未验证就不能写已解决。

最终回复先给成片和规格，再简要汇报本次兜底了什么、结果如何、还缺什么验证，以及如何完善。无兜底则写“本次无异常兜底”。改进建议区分：适合固化的确定性修复、应保留Agent判断的事项、尚需实测的候选；不要每次兜底就扩建自动化或把本片选择写进全局偏好。成片符合范围且兜底经过检查即为正常完成，不以脚本独立跑完为完成标准。
